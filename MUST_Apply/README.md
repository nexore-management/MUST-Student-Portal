# MUST Apply — GitHub Pages Demonstration

A static front-end demonstration of the MUST Apply student portal.

## Open the website

After publishing this repository with GitHub Pages, open the Pages URL provided by GitHub. The home page is `index.html`.

## Pages included

- `index.html` — portal home page
- `login.html` — sign-in form demonstration
- `register.html` — account registration form demonstration
- `dashboard.html` — sample student dashboard
- `css/style.css` — website styling

## Technologies

- HTML5
- CSS3
- JavaScript

## Important: front-end demonstration only

GitHub Pages hosts static websites. It does not execute PHP or connect directly to a MySQL database.

For that reason, the login and registration pages in this version only demonstrate the interface and browser-side form validation. They do **not** create accounts, authenticate users, save passwords, or retrieve student records.

The original PHP/MySQL version must remain on a PHP-capable web host (such as your existing InfinityFree hosting) unless you later connect this front end to a separately hosted backend/API.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the files in this folder.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub to publish the site. The Pages URL will appear in the same settings section.

This is an academic prototype, not an official university admissions website.
